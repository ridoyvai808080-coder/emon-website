# ইমন ভাইয়ের ওয়েবসাইট

GitHub Pages-এ প্রকাশ করার জন্য প্রস্তুত static website.

## ফাইল
- `index.html` — মূল ওয়েবসাইট
- `style.css` — ডিজাইন
- `script.js` — ২০০টি একবার-ব্যবহারযোগ্য password gate
- `EMON-Panel-Sance-2.0.apk` — আপনার দেওয়া APK
- `app_icon.png` — APK থেকে নেওয়া icon

## ভিডিও ওয়ালপেপার
একটি `wallpaper.mp4` ফাইল এই একই folder-এ রাখুন। সাইট সেটি background video হিসেবে চালাবে। ভিডিও না থাকলে animated background দেখা যাবে।

## GitHub Pages
সব ফাইল repository-এর root-এ upload করুন → Settings → Pages → Deploy from a branch → `main` / root নির্বাচন করুন।

> গুরুত্বপূর্ণ: password gateটি browser-side JavaScript। তাই এটি নিরাপদ server authentication নয়। সত্যিকারের নিরাপত্তার জন্য backend/database দরকার।
